태양광 검토, 어떤 자료를 누구에게 확인해야 할까요?

운영: 두자건설(DOOJA) · 작성·내용 업데이트: 2026년 10월 23일

태양광 검토는 설치 목적과 현장 조건을 바탕으로 배치, 예상 발전량, 구조안전, 전기 연결, 공사 범위를 확인하는 과정입니다. 이 안내에서는 처음 상담할 때 서로 다른 검토 내용을 구분하고, 확인된 조건과 남은 질문을 정리하는 방법을 설명합니다.

건물주는 준비할 자료를, 시공사는 분야별 담당자에게 전달할 정보를 찾아볼 수 있습니다. 개별 현장의 설치 가능 여부나 구조안전 결과를 이 글만으로 결정하지 않습니다.

‘태양광을 설치할 수 있나요?’라는 질문에는 서로 다른 확인이 필요합니다. 견적서나 상담 회신에 어느 범위가 포함됐는지 표시하면 미확인 항목을 찾기 쉽습니다.

발전량은 발전량 예측 조건, 비용은 견적 비교 항목, 공사 완료 후 자료는 인수인계 목록에서 자세히 확인할 수 있습니다. 계통 연계와 인허가의 실제 요건·가능 여부는 해당 현장과 시점을 기준으로 담당 기관에 확인하세요.

2. 태양광 검토와 태양광 구조검토는 어떻게 다른가요?

태양광 구조검토는 전체 설치 검토 중 구조안전에 관한 업무입니다. 모듈과 지지대의 무게, 바람·눈 등의 하중이 고정부를 거쳐 기존 지붕이나 기초에 전달되는 조건을 검토합니다. 발전량 예측이나 견적 비교는 확인 대상과 결과물이 다릅니다.

구조계산서를 받았다면 적용한 도면, 검토 대상과 조건을 확인합니다. 구조검토 결과만으로 예상 발전량이나 전체 공사 비용까지 확인된 것은 아닙니다. 태양광 구조검토 항목·준비자료와 구조계산서 확인법을 함께 살펴보세요.

3. 현재 단계에 맞게 자료를 준비하세요

용량과 도면이 아직 정해지지 않았다면

설치 장소, 사용 목적, 현재 보유한 건물 자료와 확인하지 못한 사항을 정리합니다. 사진은 촬영 위치와 날짜를 붙여 전달하고, 현장 접근이 필요한 조사는 안전한 절차를 갖춘 담당자와 협의합니다. 설치 전 상담 체크리스트로 시작할 수 있습니다.

발전량 제안이나 견적을 받았다면

제안별 모듈 사양·배치와 공사 범위를 나란히 놓고 비교합니다. 서로 다른 배치로 계산된 발전량과 다른 공사 범위의 총액은 직접 비교하기 어렵습니다. 구조검토·보강·방수와 추가 확인 항목이 어디에 포함됐는지도 표시하세요.

설치 계획이 바뀌었다면

변경 전후 도면, 제품 사양과 변경 이유를 모읍니다. 발전량 예측, 구조검토, 견적이 각각 어느 계획을 기준으로 작성됐는지 확인하고, 영향 범위는 분야별 담당자에게 묻습니다. 설계 변경자료 정리 예시를 참고하세요.

4. 분야별 결과가 같은 설치 계획을 기준으로 하는지 확인하세요

자료를 모으는 것만큼 중요한 것은 서로 같은 조건을 다루고 있는지 확인하는 일입니다. 배치도를 수정했다면 이전 도면으로 작성한 예측값이나 검토서가 남아 있는지 살펴보세요.

  1. 기준 자료 표시: 검토에 사용할 배치도 번호·작성일·개정번호와 제품 사양을 함께 전달합니다.
  2. 범위 구분: 각 담당자가 확인한 대상, 사용한 자료와 제외한 항목을 적습니다.
  3. 미결 사항 분리: 현장 조사, 제품 확정, 기관 협의 등 아직 끝나지 않은 내용을 별도 목록으로 남깁니다.
  4. 변경 영향 확인: 변경된 부분을 관련 담당자에게 전달하고 기존 결과의 적용 여부와 추가 확인 범위를 회신받습니다.
예를 들어 확인해 볼 상황

옥상 설비의 그림자를 피하려고 모듈 위치를 옮겼다면, 발전량 예측에 반영한 배치와 구조검토 도면의 지지 위치가 함께 바뀌었는지 확인해야 합니다. 이는 확인 방법을 설명하는 가상 상황이며 실제 두자 현장의 검토 결과가 아닙니다.

5. 검토 현황을 한 문서에 정리하세요

메일·견적서·도면에 흩어진 회신은 아래 항목으로 묶어 두면 후속 협의가 편해집니다. ‘확인 완료’라는 표시에는 근거 자료와 적용 범위를 함께 적습니다.

  • 현장과 목적: 대상 건물·설치 구역, 사용 목적, 현재 단계
  • 기준 자료: 배치도·제품 사양의 파일명, 작성일과 개정번호
  • 검토 분야와 담당: 확인을 요청한 업무, 담당자, 요청·회신 날짜
  • 확인된 조건: 적용 범위와 결과 문서, 후속 작업에 반영할 사항
  • 미확인 내용: 필요한 추가 자료, 다음 확인 담당자와 협의 일정

구조검토를 의뢰할 때 사용할 빈 양식은 구조검토 상담 준비 양식에서 내려받을 수 있습니다. 이 목록이나 양식은 담당자의 검토 결과서를 대신하지 않습니다.

자주 묻는 질문

설비 용량이 같으면 검토 결과도 같나요?

같은 kW라도 제품 크기·무게, 모듈 배치, 지지 위치와 현장 조건이 다를 수 있습니다. 용량 수치만으로 발전량과 구조안전 결과가 같다고 판단하지 않습니다.

자료가 모두 있어야 상담할 수 있나요?

현재 보유한 자료와 없는 자료를 구분해 전달할 수 있습니다. 부족한 자료를 임의로 추정하지 말고, 추가 조사와 자료 준비 범위를 담당자와 협의하세요.

태양광검토나 태양광구조검토를 문의할 때 무엇을 알려야 하나요?

현장 주소·설치 형식·현재 단계와 함께 궁금한 항목을 알려주세요. 발전량, 공사 범위, 기존 건물 구조안전 등 필요한 업무를 구분하면 알맞은 자료와 결과물 범위를 협의할 수 있습니다.
